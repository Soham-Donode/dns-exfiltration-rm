1. Executive Summary & Operational Threat Model

The Domain Name System (DNS) is the foundational address-resolution protocol of the Internet. Because enterprise networks, cloud instances, and edge devices fundamentally depend on continuous recursive DNS queries to function, outbound UDP/TCP port 53 traffic is almost universally permitted across firewalls, proxies, and next-generation security gateways. This ubiquitous trust makes DNS one of the primary vectors for covert command-and-control (C2) channels and data exfiltration (MITRE ATT&CK Technique T1071.004 and T1048.003).

Adversarial tunneling utilities—such as iodine, dnscat2, and dns2tcp—exploit the protocol by partitioning classified files, credentials, or remote shells into encoded substrings and prepending them as subdomain labels destined for an attacker-controlled authoritative nameserver. Because standard network security inspection cannot blindly terminate all port 53 traffic without disabling enterprise connectivity, automated detection requires robust mathematical feature extraction and machine learning classification capable of differentiating benign user behavior from stealthy exfiltration patterns.

3. Phase 2 (Week 2) — Scapy Simulation Engine & RFC Compliance

Attackers cannot transmit arbitrary byte streams over DNS without adhering to the syntactic rules enforced by intermediate recursive resolvers (e.g., Google 8.8.8.8, Cloudflare 1.1.1.1). If an exfiltration query violates RFC 1035, standard resolvers immediately drop the packet with an RCODE: FORMERR (Format Error) before it ever reaches the attacker's authoritative server.

In Week 2, we built the DNSExfiltrationSimulator module to emulate realistic attacker toolchains under RFC constraints:

RFC 1035 & Encoding Constraints: 1. Label Length: Length(Label_i) <= 63 octets
2. Total FQDN: Sum(Length(Label_i) + 1) <= 253 octets (excluding root null octet)
3. Allowed Chars: [a-zA-Z0-9-] (Hyphen cannot be leading or trailing in any label)
4. Base32 (RFC 4648): Strips '=' padding because '=' is illegal in standard hostname labels.
5. Chunking Formula: Chunk_Size = 63 - len(seq_prefix) - len(attacker_apex_domain)

Technical Relevance & Operational Context (Week 2 Output):

1. Deterministic Sequencing: DNS utilizes connectionless UDP transport. In real networks, packets may arrive out-of-order or experience packet loss. Attackers prepend monotonic sequence headers (sq0001, sq0002) to allow server-side reassembly. Our feature extractor identifies these predictable sequence markers.

2. Padding Stripping: Standard Base32 encoders append = characters for 8-byte alignment. If transmitted unmodified, DNS recursive resolvers reject the query. Stripping the padding mimics real-world malware evasion and creates distinct trailing character distributions.

3. Record Type Multiplicity: While classical exfiltration relied on A records (IPv4 responses), advanced C2 channels (such as Cobalt Strike DNS beacons and iodine) leverage TXT records to pack up to 255 bytes of return payload in downstream responses. The engine implements full Scapy support for A, TXT, AAAA, and CNAME.

4. Phase 3 (Week 3) — Traffic Capture & Synthesis

In enterprise networks, malicious exfiltration does not occur in an isolated vacuum; it is interleaved into an overwhelming background stream of legitimate web browsing, telemetry, and background API queries. Furthermore, adversaries deploy two radically distinct operational modes:

  • Burst Exfiltration: High query volume transmitted with minimal inter-packet arrival times (Δt < 0.1s). This occurs when an attacker attempts to rapidly dump database tables or documents before incident response teams isolate the infected host.
  • Low-and-Slow Covert Exfiltration: Micro-burst queries transmitted with jittered, protracted delays (Δt > 5.0s to several minutes). This tactic intentionally evades volume-based threshold alerts in Security Information and Event Management (SIEM) systems.

Technical Relevance & Operational Context (Week 3 Output):

1. Balanced Ground Truth: Machine learning algorithms trained on severely imbalanced datasets (e.g., 99.9% benign) suffer from majority-class collapse, where models achieve high "accuracy" simply by classifying every single packet as benign. A controlled 60/55 split enables rigorous evaluation of precision, recall, and false alarm rates without artificial weighting tricks.

2. Temporal Limitations Exposed: If an intrusion detection system relies solely on query frequency or bandwidth thresholds, it catches Burst exfiltration but completely misses Low-and-Slow exfiltration. This necessitates the extraction of invariant structural and lexical features developed in Week 4.

3. Dual Export (PCAP + CSV): Saving raw PCAPs enables replay in hardware appliances (Snort, Zeek, Suricata), while parsed CSVs feed directly into our machine learning feature engineering pipeline.

Output 3: Information-Theoretic Shannon Entropy Distributions

Cell 6 computes the Shannon entropy $H(X)$ of character distributions across the full FQDN and the isolated subdomain components. Shannon entropy measures the average amount of information (in bits per symbol) contained in the string:

Shannon Entropy Formulation: H(X) = - ∑ P(x_i) · log_2 P(x_i)
where P(x_i) is the empirical probability of character x_i in the domain string, evaluated over all unique characters.

9. Production Deployment Architecture & Future Roadmap

To translate this framework into real-time enterprise protection, we recommend the following deployment topology:

  1. DNS Resolver Sensor Tap: Deploy a packet capture tap (via CoreDNS plugins, BIND query logging, or Zeek scripts) that streams raw DNS query logs into a message queue (e.g. Apache Kafka).
  2. Feature Extraction Microservice: A stateless Python/Go worker calculates the top 8 discriminating features (max_label_entropy, domain_len, subdomain_len, entropy, etc.) at line rate.
  3. Model Scoring & RPZ Enforcement: The persisted best_dns_detector.joblib scores incoming queries. Queries with P(Exfil) ≥ 0.50 are routed to an automated Response Policy Zone (RPZ) that sinkholes the attacker domain, neutralizing the exfiltration tunnel in real time.
Roadmap for Weeks 6–8:
  • Character N-Gram Language Modeling: Integrate character-level bi-gram and tri-gram probabilities to catch sub-10-character exfiltration micro-payloads.
  • Sequence Modeling via Recurrent Networks / Transformers: Model multi-query sessions to detect distributed Low-and-Slow attacks where individual queries appear benign but the multi-hour sequence exhibits high information density.
  • Real-time Streaming Docker Container: Package the visual simulation runner (src/simulate.py) and detector into a turnkey Docker container for SOC deployment.
