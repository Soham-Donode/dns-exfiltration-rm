# Datasets: Acquisition, Synthesis, and Feature Directory Guide

This directory houses raw and processed datasets for simulating, capturing, engineering features, and detecting DNS data exfiltration and tunneling attacks.

---

## Directory Organization

```text
data/
├── raw/                              # Untouched captures and source domain lists (Gitignored)
│   ├── top-1m.csv                    # Tranco Top 1M benign domain list
│   ├── sample_capture.pcap           # Baseline packet capture
│   ├── traffic_capture.pcap          # Live or synthesized mixed traffic PCAP
│   ├── synthesized_traffic.pcap      # Multi-profile synthesized PCAP session
│   └── cic_bell/                     # CIC-Bell-DNS-EXF-2021 dataset files
│       └── cic_bell_sample.csv       # Synthetic benchmark sample for offline testing
│
└── processed/                        # Structured, labeled data ready for ML (Gitignored)
    ├── labeled_traffic.csv           # Parsed and labeled DNS query events
    └── dns_features.csv              # 24-feature engineered matrix for ML training
```

## 1. Benign Dataset: Tranco Top 1M

The **Tranco list** provides an evasion-resistant ranking of top Internet domains synthesized across Alexa, Cisco Umbrella, Majestic, and Farsight over 30 days.

### Automatic Download & Subsetting:
```bash
# Download and extract full Top-1M list
python3 src/download_data.py --tranco

# Download and create a 50,000 domain sample for rapid testing
python3 src/download_data.py --tranco --sample-size 50000
```

### Manual Download (curl/wget):
```bash
curl -L -o data/raw/top-1m.csv.zip https://tranco-list.eu/top-1m.csv.zip
unzip data/raw/top-1m.csv.zip -d data/raw/
```

## 2. Malicious Dataset: CIC-Bell-DNS-EXF-2021

The **CIC-Bell-DNS-EXF-2021** dataset, created by the Canadian Institute for Cybersecurity (University of New Brunswick) and Bell Canada, captures tunneling and exfiltration generated by standard adversary tools:
- `iodine` (Base32/Base64/Base128 tunneling over DNS)
- `dnscat2` (C2 tunneling and encrypted command transmission)
- `dns2tcp` (TCP connection encapsulation over DNS queries)

### Acquisition Instructions:
1. Visit the UNB CIC dataset repository: [CIC-Bell-DNS-EXF-2021 Portal](https://www.unb.ca/cic/datasets/dns-exf-2021.html)
2. Submit the academic access request form to receive download credentials.
3. Extract the downloaded PCAPs or CSVs into `data/raw/cic_bell/`.
4. Verify the dataset installation:
   ```bash
   python3 src/download_data.py --check-cic
   ```

### Synthetic Benchmark Fallback:
If you do not currently have access credentials for the UNB portal, generate a reproducible synthetic CIC-Bell benchmark dataset:
```bash
python3 src/download_data.py --generate-cic-sample
```

## 3. Traffic Simulation & Packet Synthesis (Week 2 & Week 3)

Generate mixed traffic sessions containing benign queries, burst exfiltration, and low-and-slow exfiltration:

```bash
# Synthesize 300 benign queries, 200 burst exfil queries, and 80 low-and-slow queries:
python3 src/capture_traffic.py --synthesize \
    --benign-count 300 \
    --burst-count 200 \
    --low-slow-count 80 \
    --pcap-out data/raw/synthesized_traffic.pcap \
    --output-csv data/processed/labeled_traffic.csv
```

### Live Capture with tcpdump:
```bash
# Capture live port 53 traffic using tcpdump:
sudo tcpdump -i lo -c 100 -w data/raw/traffic_capture.pcap -nn udp port 53

# Parse captured PCAP and produce ground-truth labeled CSV:
python3 src/capture_traffic.py --pcap data/raw/traffic_capture.pcap --output-csv data/processed/labeled_traffic.csv
```

## 4. Feature Matrix Schema (`data/processed/dns_features.csv`)

Transforming labeled DNS queries into numeric feature vectors yields 24 features across 4 categories:

| Feature Category | Features Included | Description |
|---|---|---|
| **Information Theory** | `entropy`, `subdomain_entropy`, `max_label_entropy` | Shannon entropy (in bits) measuring character randomness. |
| **Length Metrics** | `domain_len`, `subdomain_len`, `num_labels`, `max_label_len`, `min_label_len`, `avg_label_len` | Structural dimensions governed by RFC 1035 limits. |
| **Character Ratios** | `digit_ratio`, `alpha_ratio`, `hex_ratio`, `vowel_ratio`, `consonant_ratio`, `vowel_consonant_ratio`, `special_ratio`, `subdomain_digit_ratio`, `subdomain_hex_ratio`, `unique_char_ratio` | Lexical distributions identifying encoding fingerprints. |
| **Linguistic Metrics** | `max_consecutive_consonants` | Phonetic streaks atypical of human natural language. |
| **Temporal Frequency** | `queries_per_minute` | Rolling rate per domain/client to detect burst velocity. |
| **Target Label** | `label`, `attack_type` | Ground truth: `0` (benign) or `1` (malicious / exfiltration). |
